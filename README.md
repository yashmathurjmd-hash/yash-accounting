# YASH Accounting V50

This repository contains a V50-aligned YASH Accounting starter project built for a professional accounting/GST ERP workflow.

## Included
- Frontend: React + Vite + Ant Design
- Backend: Node.js + Express
- Mock accounting data for dashboard, masters, vouchers, reports, admin
- PAKKA / KACCHA / MIXED book selector
- Voucher entry workflow
- Keyboard shortcuts: Enter to move next field, Ctrl+Enter to save
- Reporting and admin sections

## Folder structure
- `frontend/` — React frontend
- `backend/` — Express API server

## Run locally

### 1) Install dependencies
```bash
cd backend && npm install
cd ../frontend && npm install
```

### 2) Start backend
```bash
cd backend
npm run dev
```

### 3) Start frontend
```bash
cd frontend
npm run dev
```

Frontend runs on `http://localhost:5173`
Backend runs on `http://localhost:4000`
